# Qadam Market — конкурсный интернет-магазин сельхозпродукции

Адаптивный демонстрационный магазин в кремово-зелёном стиле. Проект работает на Node.js + Express и не требует сборки фронтенда.

## Что реализовано

- Главная страница, рекламный баннер, категории, промо-блок и отзывы.
- Каталог с карточками товаров: изображения, бренд, описание, цена/старая цена, рейтинг, упаковка и остаток.
- Поиск, фильтры по категории и возрасту, сортировка по цене и рейтингу.
- Подробная карточка товара.
- Корзина с изменением количества, удалением и автоматическим подсчётом суммы. Корзина хранится в браузере.
- Демонстрационное оформление заказа. Заказы сохраняются на сервере в `data/db.json`; оплаты нет.
- Панель администратора: добавление, редактирование и удаление товаров, редактирование текста/изображения главного баннера и промо, просмотр заказов и изменение статуса заказа.
- Адаптивная вёрстка для мобильных устройств и компьютеров.

## Требования

- Node.js 18 или новее.
- Интернет нужен для загрузки Google Fonts и внешних фотографий; сам сервер работает локально.

## Запуск на своём компьютере

1. Установите Node.js с сайта https://nodejs.org/ (LTS).
2. Распакуйте архив в папку.
3. Откройте терминал в папке `qadam-market`.
4. Выполните:

   ```bash
   npm install
   npm start
   ```

5. На этом компьютере откройте http://localhost:3000.

### Показ на втором компьютере в той же сети

1. Подключите оба компьютера к одной Wi-Fi/локальной сети.
2. На компьютере-сервере узнайте локальный IP-адрес:
   - Windows: `ipconfig`
   - macOS/Linux: `ip addr` или `ifconfig`
3. На втором компьютере откройте `http://IP-АДРЕС-СЕРВЕРА:3000`, например `http://192.168.1.25:3000`.
4. Если страница не открывается, разрешите входящие подключения к порту 3000 в брандмауэре. Некоторые гостевые Wi-Fi сети запрещают связь между устройствами.

Сервер слушает `0.0.0.0`, поэтому доступ из локальной сети предусмотрен.

## Панель администратора

- Внизу сайта нажмите «Вход для администратора».
- Пароль по умолчанию: `qadam2026`.
- Перед публикацией в интернете ОБЯЗАТЕЛЬНО задайте свой пароль через переменную окружения `ADMIN_PASSWORD`.

Пример Linux/macOS:

```bash
ADMIN_PASSWORD='сложный-длинный-пароль' npm start
```

Пример PowerShell:

```powershell
$env:ADMIN_PASSWORD='сложный-длинный-пароль'
npm start
```

Для конкурсной демонстрации пароль по умолчанию удобен, но не оставляйте его на публичном сервере.

## Публикация в интернете

Проект требует Node.js-сервера и записи в `data/db.json`. Подойдёт хостинг Node.js, который поддерживает постоянный диск (persistent disk/volume). Например, создайте Web Service на Render/Railway/Fly.io, подключите репозиторий с этими файлами, задайте команду запуска `npm start`, порт будет получен из `PORT`, а переменную `ADMIN_PASSWORD` установите в настройках сервиса.

**Важно про постоянные данные:** на многих бесплатных контейнерных хостингах локальная файловая система очищается при redeploy/restart. Для реального использования выберите постоянный диск либо замените JSON-хранилище на внешнюю базу данных. Этот проект хранит каталог и заказы в JSON-файле, что удобно для конкурса и небольшой демонстрации, но не предназначено для большого магазина или одновременного редактирования несколькими администраторами.

## Данные и фотографии

- Стартовые товары находятся в `data/db.json`.
- Админ-панель сохраняет изменения в тот же файл.
- Изображения загружаются по внешним HTTPS-ссылкам. Если ссылка перестанет работать, интерфейс покажет запасное фото.
- Товары и цены в проекте демонстрационные. Перед реальными продажами замените их актуальными данными.

## Проверка

Откройте `http://localhost:3000/api/health` — сервер должен вернуть JSON с `ok: true`.
